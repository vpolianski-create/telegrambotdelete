# Telegram Bot Cleaner

Приложение для Windows, которое помогает быстро удалить ненужные боты из
вашего аккаунта Telegram: показывает список всех ботов, с которыми у вас
есть чаты, и позволяет массово заблокировать их и/или удалить переписку.

Приложение работает через официальный Telegram API (протокол MTProto,
библиотека [Telethon](https://github.com/LonamiWebs/Telethon)) от лица
вашего собственного аккаунта — так же, как это делает официальное
приложение Telegram. Никакие данные никуда, кроме серверов Telegram, не
отправляются.

## Что делает приложение

- Показывает список ботов из ваших чатов (диалогов) в Telegram.
- Позволяет отметить нужных ботов и одним действием:
  - заблокировать бота (чтобы он больше не мог вам писать);
  - удалить чат с ботом из списка диалогов;
  - или сделать и то, и другое сразу.
- Хранит только api_id/api_hash и файл сессии Telegram локально на вашем
  компьютере (в `%APPDATA%\TelegramBotCleaner`). Пароль от аккаунта
  приложению не передаётся — используется официальный процесс входа
  Telegram по коду из SMS/приложения (и облачному паролю, если он у вас
  включён).

> Важно: то, что Telegram называет "ботом", которого вы создали через
> @BotFather (со своим токеном), — это отдельная история: удалить такого
> бота полностью может только его владелец через @BotFather. Это
> приложение решает другую, более частую задачу — очистку списка чатов
> от ботов, с которыми вы просто переписывались или на которых
> подписались, и которые вам больше не нужны.

## Быстрый старт (готовый .exe)

Проще всего — скачать уже собранный `TelegramBotCleaner.exe`:

1. В GitHub откройте вкладку **Actions** → workflow **Build Windows
   executable** → последний успешный запуск → скачайте артефакт
   `TelegramBotCleaner-windows` (внутри — готовый `.exe`).
2. Запустите `TelegramBotCleaner.exe`. Ничего устанавливать не нужно.

Либо соберите exe самостоятельно — см. раздел «Сборка .exe» ниже.

## Получение api_id и api_hash

Приложению нужны собственные ключи доступа к Telegram API (это бесплатно
и делается один раз):

1. Откройте <https://my.telegram.org> и войдите по своему номеру телефона.
2. Перейдите в **API development tools**.
3. Заполните форму создания приложения (название и описание — любые,
   например "Bot Cleaner").
4. Скопируйте выданные **App api_id** и **App api_hash**.
5. При первом запуске приложения вставьте их в соответствующие поля —
   они будут сохранены локально в `%APPDATA%\TelegramBotCleaner\config.json`
   и в дальнейшем спрашиваться не будут.

## Запуск из исходного кода

Требуется Python 3.10+ (на Windows — установщик с [python.org](https://www.python.org/downloads/),
галочка "Add python.exe to PATH").

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python src\main.py
```

## Сборка .exe локально

```bat
packaging\build_windows.bat
```

Скрипт создаст виртуальное окружение, установит зависимости (включая
PyInstaller) и соберёт `dist\TelegramBotCleaner.exe` — один файл, который
можно переносить и запускать на любом Windows-компьютере без Python.

Собрать вручную можно и так:

```bat
pip install -r requirements-dev.txt
pyinstaller packaging\TelegramBotCleaner.spec
```

## Как это работает при первом входе

1. Приложение попросит номер телефона в международном формате
   (`+79991234567`).
2. Telegram пришлёт код подтверждения в приложение (или SMS) — введите его.
3. Если на аккаунте включена двухфакторная аутентификация (облачный
   пароль), приложение попросит и его.
4. После входа появится список ботов из ваших чатов. Отметьте нужных и
   нажмите «Удалить выбранных ботов».

Данные входа (файл сессии Telethon) сохраняются локально в
`%APPDATA%\TelegramBotCleaner`, чтобы не вводить код при каждом запуске.
Никому не передавайте этот файл — с его помощью можно войти в ваш
аккаунт Telegram, как и с сессией в официальном приложении.

## Тесты

```bash
pip install -r requirements.txt
python -m unittest discover -s tests -v
```

Тесты покрывают чистую логику (фильтрацию диалогов на ботов, хранение
настроек, мост между asyncio и потоком интерфейса) без обращения к
реальному Telegram.

## Структура проекта

```
src/
  main.py                 — точка входа
  bot_cleaner/
    app.py                — интерфейс на Tkinter
    tg_client.py           — работа с Telegram через Telethon
    async_runner.py        — мост asyncio ↔ Tkinter
    config.py               — хранение api_id/api_hash и пути к сессии
tests/                     — юнит-тесты
packaging/                 — сборка .exe (PyInstaller)
.github/workflows/         — автосборка .exe в GitHub Actions
```
