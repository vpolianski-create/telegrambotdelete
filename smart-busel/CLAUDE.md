# Умный Бусел — правила проекта

Обучающее приложение для Жени (5 класс, Беларусь). Windows 11 и Android (с v1.7.0), работает офлайн; синхронизация через Firebase — по желанию, только зашифрованные данные. Родитель — не программист: после каждого шага объяснять простым языком и давать команды для PowerShell.

## Стек
Electron + Vite + React + TypeScript, Tailwind 3, Framer Motion, canvas-confetti, Zustand, Zod, Vitest, electron-builder (NSIS, без прав администратора). Шрифт — системный Segoe UI Variable (отдельные шрифты не встраиваются; на Android — системный).
Android: Capacitor 8 (`@capacitor/core|android|filesystem|app|share|screen-orientation`, `@capacitor-community/text-to-speech`), проект в `android/`. Библиотеки Firebase НЕТ — REST напрямую (`src/sync/firebase.ts`).

## Структура
- `electron/` — main/preload, JSON-хранилище в userData (`data.json`), бэкап при запуске (последние 7).
- `src/engine/` — баллы, уровни, награды (чистые функции, покрыты тестами).
- `src/store/useApp.ts` — состояние и сохранение.
- `src/content/` — Zod-схема и загрузчик. `content/subjects/*.json` — один файл = один предмет, код менять не нужно.
- `src/screens`, `src/components` — интерфейс.

## Контент
- Тексты пишем сами, оригинально. resheba.top и учебники — только как перечень тем. Никаких скраперов.
- Темы математики и «Человек и мир» взяты из оглавлений учебников родителя. Остальные предметы — предварительные, `needsReview: true`.
- Сомнительное (правила белорусского, даты) помечать `needsReview: true`; `CONTENT_REVIEW.md` создаётся командой `npm run validate-content`.
- Белорусские уроки — на белорусском, интерфейс — на русском.

## Этика
Без наказаний, потери баллов за ошибки, таймеров в заданиях и пугающих сообщений. Подсказка 1 бесплатна, 2-я — баллы пополам. После первой ошибки — наводящая подсказка (бесплатно) и вторая попытка; верно со второй попытки — 80 % баллов. Хвалим действие, а не ребёнка («нашёл сам», а не «ты умный»), конкретно и без преувеличений; обычный верный ответ — коротко «Верно». Не говорим «неправильно», «опять ошибся», «это же легко».

## Награды
Порог по умолчанию 100 баллов, награда по умолчанию «1 час игры на компьютере». PIN по умолчанию 0000.

## Android и синхронизация (v1.7.0)
- `src/platform/index.ts` — всё, что различается на Windows/Android: прогресс (`loadData/saveData`; Android — `fileStore.ts`: tmp-файл, 7 копий, восстановление), секреты синхронизации (`secretStore`: Windows — `electron/secret.ts` через safeStorage/DPAPI; Android — личная папка, исключена из бэкапа), `saveTextFile` (Android — «Поделиться»), `printPage` (Android — `PrintPlugin.java`), `onBackButton`, `applySystemTheme`. Модули Capacitor подгружаются только на Android (динамический import).
- Синхронизация: `src/sync/merge.ts` — слияние (счётчики складываются через вклады устройств `own` и `baseline`, отметки — объединение/максимум, настройки/план/lastTopic/rewardBase — последнее изменение по `sync.stamps`, исправленные ошибки — `sync.removed`; тема, шрифт, звук — у каждого устройства свои). `crypto.ts` — семейный код (20 знаков Крокфорда) → HKDF → номер семьи + ключ AES-256-GCM (AAD = семья+устройство), gzip перед шифрованием. `firebase.ts` — анонимный вход + Firestore REST (`families/{семья}/devices/{устройство}`, поля v, iv, ct, at). `service.ts` — создать/подключиться (resume/add/replace)/синхронизировать/отключить/сменить код. `index.ts` — когда синхронизироваться. Правила базы — `firestore.rules`. Данные проекта — `src/sync/firebase-config.json` (не секрет; пусто → синхронизация «не настроена»).
- `Data.sync` (служебное: deviceId, familyId, baseline, stamps, removed, lastSync) хранится в data.json; в экспорт (`snapshot()`) и в облако не попадает; `importData` его сбрасывает. Новые поля прогресса: решить, как они сливаются (merge.ts), и добавить тест в `tests/sync-merge.test.ts`.
- Вид на телефоне (v1.7.1, по просьбе родителя, Material 3): всё под `max-sm:` (уже 640 px), на компьютере вид не меняется. Шрифт Android — Roboto (класс `platform-android` на `<html>`, main.tsx), шкала размеров и переносы — в конце index.css; системное увеличение текста — не больше +15% (`MainActivity.limitTextZoom`), телефон — только портрет (кроме мультурока — на время ролика горизонтально, v1.9.0). `components/AppBar.tsx` — верхняя панель «← заголовок» (+ `phoneBottomBar` — прилипающая нижняя кнопка); урок/разминка/ошибки — без нижнего меню (`IMMERSIVE` в App.tsx). Нижнее меню — 5 пунктов, «Родителям» на телефоне — 🔒 на главной. Родительский режим на телефоне — список разделов, PIN — `components/PinPad.tsx` (`engine/pinpad.ts`). «Назад» Android: экраны перехватывают через `interceptBack` (platform). Вибрация — `HapticsPlugin.java` (встроенный отклик, без разрешения), `settings.vibration` (у каждого устройства своя), события — `HAPTIC` в audio/sfx.ts.
- Значки Android: `python3 scripts/android-icons.py` (из resources/brand/icon.png).
- Автообновление (с согласия родителя). Windows: `electron-updater` 6.8.11 (`electron/updater.ts`), источник — `build.publish` generic `…/releases/latest/download` (файл `latest.yml` с SHA-512 выкладывается в выпуск), скачивание в фоне, тихая установка при закрытии, IPC `update:get|install|state`. Android: свой плагин `UpdaterPlugin.java` (+ `UpdateResultReceiver.java`): скачивание только с GitHub этого репозитория, проверка пакета/версии/подписи, `PackageInstaller` с `USER_ACTION_NOT_REQUIRED` (Android 12+); разрешения `REQUEST_INSTALL_PACKAGES`, `UPDATE_PACKAGES_WITHOUT_USER_ACTION` (для Google Play их нужно убрать). Логика когда проверять/ставить — `src/update/auto.ts` (тест `tests/auto-update.test.ts`), поиск версии — `src/update/check.ts` (GitHub API, раз в 12 ч; тест `tests/update.test.ts`), запуск — `src/update/index.ts`, карточка — `AutoUpdateCard` в Parent.tsx. Job `release` дописывает недостающие файлы в уже созданный выпуск.
- Сборка APK: `npm run build && npx cap sync android && cd android && ./gradlew assembleDebug` (нужны JDK 21 и Android SDK). Основной путь — GitHub Actions (job `android`): подпись — секреты `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`; без них — `…-test.apk`. Версия Android (`versionCode` = мажор·10000 + минор·100 + патч) — из package.json.

## Команды (из папки smart-busel)
- `npm install`, `npm run dev` — запуск в окне Electron
- `npm run validate-content`, `npm test`, `npm run build`
- `npm run dist` — установщик в `release/` (на Windows). Основной путь: GitHub Actions `build-busel.yml` → артефакт `umny-busel-installer`.

## Правила качества кода
- Я не программист. Объясняй всё простыми словами, команды давай для Windows (PowerShell).
- Перед изменением логики баллов, наград, проверки ответов, сохранения прогресса, родительского режима и PIN — сначала напиши или обнови тест, потом меняй код.
- После каждого изменения запускай все тесты и сообщай результат: сколько прошло, сколько упало, что это значит.
- Если тест падает — ищи причину в коде. Никогда не подгоняй тест под неправильный результат и не удаляй тест, чтобы он «не мешал».
- Исправляй причину ошибки, а не её проявление. Объясни, в чём была причина.
- Не добавляй новое, если задачу можно решить, упростив или удалив лишнее.
- Работай небольшими шагами: один шаг — один коммит с понятным описанием на русском.
- Учебный контент (JSON-файлы с заданиями) и внешний вид не меняй без моей прямой просьбы.
- Новые библиотеки не устанавливай без моего согласия (кроме инструментов для тестов, если я их одобрил).
- Перед крупными изменениями показывай план и жди моего подтверждения.
