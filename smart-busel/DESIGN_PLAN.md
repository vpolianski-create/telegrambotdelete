# План редизайна «Умного Бусела» (стиль Aurora Play, версия 1.6.0)

Утверждён родителем 12.11.2026. Выполнять по шагам, строго по порядку. Перед началом каждого шага кратко сказать, что будет сделано; после шага — тесты, сборка, коммит, отчёт простыми словами, и ждать «дальше».

## 1. Что решено

- **Аист остаётся** главным героем и лицом бренда. Название «Умный Бусел» не меняется.
- Визуальная система — по мотивам бренд-бука LUMO («Aurora Play»): глубокий тёмный фон, одно крупное фиолетово-голубое свечение на главном экране, спокойные карточки, плоские кнопки, короткие анимации.
- **Новый внешний вид и боковое меню слева.**
- **Сундук остаётся.** Правила его работы (что и с какой вероятностью выпадает) не менять — только внешний вид.
- Основной текст **не меньше 16 px**, кнопки **44–48 px** (приложение для ребёнка, не плотный рабочий интерфейс).
- Добавить тему **«Как в Windows»** и сделать её стандартной для новых пользователей; у тех, кто уже выбрал тему, она сохраняется.
- Значки интерфейса — около 20 значков из открытого набора Fluent UI System Icons (лицензия MIT), **вставленные в код как SVG**. Новые npm-библиотеки не ставить.

## 2. Что не трогать

- Учебный контент (`content-src/`, `content/`), генераторы заданий, проверку ответов, начисление баллов, уровни, награды, сохранение прогресса, PIN.
- Наклейки и значки коллекции остаются эмодзи (это собранные награды).
- Поле `icon` у предметов в контенте не менять: картинки предметов подключаются в коде по `id` предмета.
- Тексты и тон («Почти! Давай разберём», без наказаний и таймеров) — как в CLAUDE.md.

## 5. Форма, шрифт, движение

- Шрифт: `"Segoe UI Variable Text", "Segoe UI Variable", "Segoe UI", system-ui, sans-serif`; заголовки — `"Segoe UI Variable Display"`. Вес 600 вместо жирного 800. Убрать пакеты `@fontsource/nunito` и `@fontsource/rubik` из зависимостей (это удаление, а не установка).
- Шкала: заголовок экрана 32–36 px, раздел 24–28 px, карточка 20 px, основной текст 16–18 px, подписи 14 px. Сохранить настройку размера шрифта (`--font-scale`).
- Отступы кратны 4 px: 8 / 12 / 16 / 24 / 32.
- Радиусы: кнопки и поля 8 px, карточки 12 px, крупные панели 16 px, блок «Продолжить» 20 px, метки-«таблетки» 999 px.
- Кнопки плоские: без нижней «выпуклой» тени, без градиента. Главная — заливка акцентом. Вторичная — карточка + граница. Состояния: наведение, нажатие, фокус (рамка обязательна), неактивная.
- Тени мягкие: светлая `0 1px 2px rgba(23,28,46,.05), 0 6px 18px rgba(23,28,46,.05)`; тёмная — карточки отделяются границей и фоном.
- Анимации: 80–140 мс для отклика, 220 мс для панелей, 320 мс для смены экрана. Никакого постоянного покачивания: у маскота убрать бесконечную анимацию «вверх-вниз». При «уменьшить движение» — только плавное появление.

## 6. Шаги

Каждый шаг — отдельный коммит на русском. После каждого: `npm run validate-content`, `npm test`, `npm run build`, отчёт (сколько тестов прошло/упало).

1. **Иконка приложения.** Подключить `resources/brand/icon.ico` и `icon.png` в `package.json` (установщик) и `electron/main.ts` (окно). `public/icon.png` заменить на `icon-256.png`.
2. **Тема «Как в Windows».** Сначала тест: настройка `theme` принимает `'system'`; новые пользователи получают `'system'`; сохранённые `'light'`/`'dark'` не меняются при загрузке. Затем код: в `App.tsx` при `'system'` тема берётся из `prefers-color-scheme` и обновляется при смене темы Windows. В родительском режиме вместо флажка — выбор из трёх: «Как в Windows», «Светлая», «Тёмная».
3. **Основа стиля.** Токены из разделов 4–5 в `src/index.css` и `tailwind.config.js`; шрифт Segoe UI Variable; убрать Rubik/Nunito; плоские кнопки; новые радиусы и тени. Экраны пока не перестраивать — только убедиться, что всё читается в обеих темах.
4. **Окно Windows.** Цвет заголовка окна под тему (`titleBarOverlay` или `backgroundColor` в `BrowserWindow`), чтобы не было белой полосы в тёмной теме. Минимальный размер окна оставить.
5. **Боковое меню.** Новый компонент оболочки: слева знак `app-mark.png` + «Умный Бусел»; пункты «Главная», «Предметы», «Мой план», «Работа над ошибками» (с числом), «Коллекция»; внизу «Родителям». Выбранный пункт — мягкая заливка + вертикальная акцентная полоска 3 px. В окне уже 1100 px меню сворачивается до значков с подсказками. Кнопки «Назад» внутри экранов оставить там, где они ведут на уровень выше (урок → предмет). Клавиатура: Tab проходит меню по порядку.
6. **Главный экран.** Сверху блок «Продолжить» (≈35–40 % высоты экрана): картинка `hero-continue.webp` справа, свечение, слева приветствие «Привет, имя!», название следующей темы, прогресс и одна главная кнопка «Продолжить». Ниже плитки: «До награды» (жёлтый прогресс, «осталось N баллов»), «Серия дней», «Цель на сегодня», «Задания дня» с сундуком, «Факт дня». Затем «Мой план на сегодня» и сетка предметов с картинками. Кнопки коллекции и «Родителям» из шапки уходят в боковое меню.
7. **Предметы.** Карточки предметов и заголовок экрана предмета — картинка `subject-*.webp` по `id` вместо эмодзи (сделать одну функцию `subjectArt(id)`; если картинки нет — показать эмодзи из контента). Приглушённая цветная подложка.
8. **Остальные экраны.** Урок, разминка, словарь, план, работа над ошибками, коллекция, грамоты, родительский режим: новые карточки, кнопки, отступы. Логику не менять. Грамоты при печати должны выглядеть как раньше (светлый фон).
9. **Аист по ситуации.** В `Mascot` уже есть настроения (`Mood`: `idle`, `cheer`, `think`, `support`) — расширить их, не ломая существующие вызовы: `idle` → `mascot-wave`, `cheer` → `mascot-cheer`, `think` → `mascot-think`, `support` → `mascot-encourage`; добавить `read` → `mascot-read` и `rest` → `mascot-rest`. Картинки брать из `src/assets/brand/` (сейчас `import.meta.glob` ищет `../assets/mascot-*.png` — заменить на явный список). Убрать бесконечное покачивание и значки-эмодзи настроения (🎉💡💪): поза уже показывает настроение; анимация — одно короткое появление. Украшение из сундука по-прежнему значком в углу. Расставить позы по таблице раздела 3.
10. **Награды.** Вместо конфетти на весь экран — эффект «искра»: короткая вспышка и 6–12 частиц возле аиста, 600–1000 мс, один раз (можно на canvas-confetti с малым числом частиц и цветами `#F6C453`, `#A495FF`, `#45D7F2`). Экран награды и нового уровня: тёмная карточка по центру со свечением, `mascot-cheer`, текст и одна кнопка. Сундук — новый вид, механика та же.
11. **Значки интерфейса.** Эмодзи в меню, кнопках, вкладках словаря, статусах заменить SVG-значками Fluent (компонент `Icon` с набором путей внутри файла, размеры 20 и 24 px, цвет `currentColor`). У значков без подписи — `aria-label` или подсказка.
12. **Завершение.** Удалить старые картинки без ссылок; обновить `BRANDBOOK.md` (новые цвета, шрифт, маскот, иконка) и `docs/brand/brandbook.html` при необходимости; раздел «Состояние» в `CLAUDE.md`; версия 1.6.0 в `package.json`; открыть запрос на слияние со списком изменений.
