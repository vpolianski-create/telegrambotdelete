# Перечень тем для сверки с учебниками

Тексты уроков написаны оригинально; учебники использованы только как перечень тем.

| Предмет | Источник перечня тем | Статус |
|---|---|---|
| Математика (часть 1) | оглавление учебника родителя (§1–20) | готовы 2 темы: «Округление», «Деление с остатком» |
| История Древнего мира | оглавление учебника родителя (§1–29) | только перечень тем |
| Человек и мир | оглавление учебника родителя (§1–31) | только перечень тем |
| Русский язык, Русская литература, Беларуская мова, Беларуская літаратура, Английский язык | **черновик по моим знаниям** | нужна сверка: пришлите оглавления |

Английские слова («Семья», «Школа») — транскрипция и переводы помечены `needsReview`.
Полный список мест на проверку создаётся командой `npm run validate-content` в файле `CONTENT_REVIEW.md`.
