# Перечень тем для сверки с учебниками

Тексты уроков написаны оригинально; учебники использованы только как перечень тем.

| Предмет | Источник перечня тем | Готовые уроки |
|---|---|---|
| Математика (часть 1) | оглавление учебника (§1–20) | §7 Округление, §10 Степень, §11 Деление с остатком, §12 НОД и НОК, §13 Признаки делимости, §17 Уравнение |
| История Древнего мира | оглавление учебника (§1–29) | §2 Счёт лет в истории |
| Человек и мир | оглавление учебника (§1–31) | §6 Солнечная система |
| Русский язык | оглавление учебника (§1–27) | §5 Части речи, §18 Виды предложений |
| Русская литература | оглавление учебника | только перечень тем |
| Беларуская літаратура | змест вучэбнага дапаможніка | только перечень тем |
| Беларуская мова | **черновик по моим знаниям** — нужно оглавление | только перечень тем |
| Английский язык | **черновик по моим знаниям** — нужно оглавление | «to be» + слова «Семья», «Школа» |

Английские слова — транскрипция и переводы помечены `needsReview`.
Полный список мест на проверку создаётся командой `npm run validate-content` в файле `CONTENT_REVIEW.md`.
