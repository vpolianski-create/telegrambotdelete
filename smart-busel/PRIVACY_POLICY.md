# Политика конфиденциальности приложения «Умный Бусел»

*Действует с версии 1.7.0. Дата: 14 ноября 2026 г.*

«Умный Бусел» — обучающее приложение для школьника 5 класса (Windows и Android). Приложение сделано для одной семьи и не содержит рекламы, встроенных покупок, аналитики и счётчиков посещений.

## Какие данные есть в приложении

- **Учебный прогресс:** баллы, пройденные темы, результаты, ошибки для повторения, выученные слова, значки, награды, время занятий по дням.
- **Настройки:** имя ребёнка (как его ввёл родитель), PIN родительского режима, тексты наград, дневная цель и ограничения времени, оформление.

Приложение **не собирает** геолокацию, контакты, фото, звук, сведения об устройстве, рекламный идентификатор и не просит таких разрешений. На Android у приложения одно разрешение — доступ в Интернет (для синхронизации).

## Где хранятся данные

По умолчанию — **только на устройстве**, в личной папке приложения. На Android файл прогресса может попасть в резервную копию Google вашего устройства (если она включена в настройках телефона); семейный код синхронизации в неё не попадает.

## Синхронизация между устройствами (по желанию)

Если родитель включает синхронизацию в родительском режиме:

- Прогресс и настройки **шифруются на устройстве** (AES-256-GCM) ключом, который выводится из семейного кода. Код создаёт само приложение, он хранится только на устройствах семьи.
- Зашифрованные данные хранятся в облачной базе **Google Firebase (Cloud Firestore)**. Ни Google, ни разработчик не могут прочитать их без семейного кода.
- Для доступа к базе используется **анонимный вход Firebase Authentication**: без почты, телефона и пароля. Google при этом обрабатывает технические данные (временный идентификатор входа, IP-адрес запроса) по своей политике: https://firebase.google.com/support/privacy
- Данные передаются только по защищённому соединению (HTTPS).

## Передача третьим лицам

Данные не продаются и никому не передаются. Единственный внешний сервис — Google Firebase (только при включённой синхронизации, только в зашифрованном виде).

## Удаление данных

- **Из облака:** Родительский режим → Синхронизация → «Удалить данные из облака». Удаляются все данные семьи в облаке и анонимная учётная запись этого устройства.
- **С устройства:** удаление приложения удаляет все его данные с устройства.
- Можно в любой момент отключить синхронизацию на отдельном устройстве или сменить семейный код.

## Дети

Приложение предназначено для детей и используется под контролем родителя: синхронизацию включает и выключает только родитель (раздел защищён PIN). Приложение не показывает рекламу и не содержит ссылок на внешние сайты и покупок.
