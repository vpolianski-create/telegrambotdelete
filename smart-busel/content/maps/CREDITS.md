# Источник карт

Контуры суши, границы стран и реки взяты из набора **Natural Earth** (https://www.naturalearthdata.com) — это данные в общественном достоянии, их можно свободно использовать.

Файлы `*.json` в этой папке собраны из них командой `node scripts/build-maps.mjs <папка с данными>`:
- `world` — суша мира (масштаб 1:110 млн);
- `ancient`, `mediterranean`, `neareast`, `empire`, `greece` — суша (1:50 млн) и реки (1:10 млн);
- `belarus` — границы стран (1:50 млн) и реки (1:10 млн).

Города, области и моря на карты ставит сборка уроков по справочнику `content-src/places.mjs`; на карте темы есть только те места, которые названы в тексте этой темы.
