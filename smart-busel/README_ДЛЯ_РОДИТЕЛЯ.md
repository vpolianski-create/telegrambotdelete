# «Умный Бусел» — инструкция для родителя

Обучающее приложение для Жени (5 класс). Работает **без интернета**, ничего не отправляет наружу. Всё хранится на этом компьютере.

## 1. Где взять установщик

Установщик собирается автоматически на GitHub. Доставать ничего из программ не нужно.

1. Откройте репозиторий на GitHub → вкладка **Actions** → слева **Build Smart Busel installer**.
2. Выберите самый верхний запуск с зелёной галочкой ✓.
3. Внизу страницы в разделе **Artifacts** скачайте `umny-busel-installer` (это ZIP-архив).
4. Распакуйте архив (правая кнопка → «Извлечь всё»). Внутри файл `Umny-Busel-Setup-1.0.0.exe`.

*Подсказка:* если красная галочка ✗ вместо зелёной, откройте предыдущий успешный запуск или напишите мне.

## 2. Установка (около минуты)

1. Дважды щёлкните по `Umny-Busel-Setup-1.0.0.exe`. Права администратора **не нужны**.
2. Если Windows показывает синее окно «Windows защитила ваш компьютер» — это нормально для новых программ без платной подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Установка пройдёт сама, приложение запустится. Ярлык «Умный Бусел» появится на рабочем столе и в меню «Пуск».

## 3. Первый запуск — что сделать родителю

1. Нажмите на значок 🔒 в правом верхнем углу → введите PIN **0000**.
2. Сразу **смените PIN** (жёлтая рамка вверху) на 4–6 цифр, которые Женя не знает.
3. Вкладка **«Настройки»**: проверьте имя, дневную цель (заданий в день), дневной лимит времени (0 = без лимита), напоминание о перерыве (по умолчанию каждые 30 минут), звук, тёмную тему, размер шрифта.
4. Вкладка **«Награды»**: порог по умолчанию — каждые **100 баллов**, награда — «1 час игры на компьютере». Можно изменить порог и задать свои награды для конкретных баллов (например, «300 — кино»).

## 4. Как это работает для Жени

- На главном экране: приветствие с аистом Буселом, шкала до награды, серия дней 🔥, цель на сегодня, кнопка «Продолжить» и плитки предметов.
- Урок идёт по шагам: **объяснение → разобранный пример → «Проверь себя» → практика → бонус (по желанию) → итог**.
- За ошибки баллы **не отнимаются**. Приложение мягко разбирает решение и даёт похожее задание. Первая подсказка бесплатная, вторая уменьшает баллы вдвое.
- Баллы: обычное задание — 10, повышенное — 20, бонусное — 30, комбо из 5 подряд — +10, тема на 80% и выше — +50 и значок, дневная цель — +20.
- После каждой пройденной темы — сундук-сюрприз (стикер, наряд для Бусела или баллы). Наряды также открываются за новые уровни.
- Серия дней: один пропущенный день в неделю прощается автоматически («заморозка» ❄️). Ничего не пропадает.

## 5. Как выдавать награды

Когда Женя набирает порог, на весь экран появляется поздравление: «Женя, ты заработал 100 баллов! 🎁 Подойди к родителям и попроси свою награду». На главном экране остаётся значок 🎁 с числом невыданных наград.

Когда выдали награду: 🔒 → PIN → **«Награды»** → кнопка **«Выдана»**. Статус сменится на «Выдана ✓».

## 6. Статистика

🔒 → **«Статистика»**: время занятий по дням (за неделю), процент правильных ответов по предметам, пройденные и начатые темы, темы с частыми ошибками.

## 7. Что есть сейчас и что ещё впереди

**Готовые уроки** (остальные темы показаны в списке с пометкой «Скоро»):
- Математика: округление, степень, деление с остатком, НОД и НОК, признаки делимости, уравнение.
- История Древнего мира: счёт лет.
- Человек и мир: Солнечная система.
- Русский язык: части речи, виды предложений.
- Английский: глагол to be, 40 слов («Семья», «Школа») с озвучкой, карточками, играми и повторением по системе Лейтнера.

**Важно проверить:** все тексты написаны мной оригинально по темам из ваших учебников. Места, в которых я не уверен (даты, правила, перевод слов), собраны в файле `smart-busel/CONTENT_REVIEW.md`. Пожалуйста, просмотрите их с учебником и скажите, что поправить.

Темы для белорусского языка и английского грамматики пока составлены мной приблизительно (`CURRICULUM_REVIEW.md`). Пришлите оглавления учебников, и я сверю.

## 8. Озвучка английских слов

Приложение использует голоса Windows. Если слова не озвучиваются (на экране слов будет подсказка 🔇):
**Параметры Windows → Время и язык → Язык и регион → Добавить язык → English (United States)**, затем в его параметрах скачайте пакет **«Речь»** (Speech). После этого перезапустите приложение.

## 9. Резервные копии и перенос прогресса

- Прогресс сохраняется автоматически в `C:\Users\<имя>\AppData\Roaming\Умный Бусел\data.json`.
- При каждом запуске приложение делает копию в папке `backups` рядом (хранятся последние 7).
- Вручную: 🔒 → **«Копия»** → **«Сохранить в файл»** (и «Загрузить из файла» на другом компьютере).

## 10. Если что-то пошло не так

- **Забыли PIN.** Закройте приложение, откройте папку `C:\Users\<имя>\AppData\Roaming\Умный Бусел`, откройте `data.json` в Блокноте, найдите строку `"pin"` и впишите новое значение (например, `"pin": "0000"`). Сохраните.
- **Приложение не открывается.** Переустановите его: прогресс останется на месте (хранится отдельно от программы).
- **Удалить приложение:** Параметры → Приложения → «Умный Бусел» → Удалить.
