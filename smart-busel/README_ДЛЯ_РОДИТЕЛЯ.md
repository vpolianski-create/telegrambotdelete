# «Умный Бусел» — инструкция для родителя

Обучающее приложение для Жени (5 класс). Есть версия для **Windows** и для **Android** (телефон, планшет). Работает **без интернета**. Если включить синхронизацию (по желанию, раздел 12), прогресс будет общим на всех устройствах: в облако Google он уходит только **в зашифрованном виде**.

## 1. Где взять установщик

Установщик собирается автоматически на GitHub и выкладывается на странице выпусков. Ставить вручную нужно только один раз — дальше программа обновляется сама (раздел 14).

1. Откройте репозиторий на GitHub → справа **Releases** → самый верхний выпуск «Умный Бусел X.Y.Z».
2. Скачайте файл `Umny-Busel-Setup-X.Y.Z.exe` (X.Y.Z — номер последней версии, например 1.10.0).

*Подсказка:* для телефона там же лежит `Umny-Busel-X.Y.Z.apk` — см. раздел 11.

## 2. Установка (около минуты)

1. Дважды щёлкните по `Umny-Busel-Setup-X.Y.Z.exe`. Права администратора **не нужны**.
2. Если Windows показывает синее окно «Windows защитила ваш компьютер» — это нормально для новых программ без платной подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Установка пройдёт сама, приложение запустится. Ярлык «Умный Бусел» появится на рабочем столе и в меню «Пуск».

## 3. Первый запуск — что сделать родителю

1. Нажмите **«Родителям»** (🔒) — на компьютере внизу левого меню, на телефоне в правом верхнем углу главного экрана → введите PIN **0000**.
2. Сразу **смените PIN** (жёлтая рамка вверху) на 4–6 цифр, которые Женя не знает.
3. Вкладка **«Настройки»**: проверьте имя, дневную цель (заданий в день), дневной лимит времени (0 = без лимита), напоминание о перерыве (по умолчанию каждые 30 минут), звук, тему (как в Windows, светлая или тёмная), размер шрифта.
4. Вкладка **«Награды»**: порог по умолчанию — каждые **100 баллов**, награда — «1 час игры на компьютере». Можно изменить порог и задать свои награды для конкретных баллов (например, «300 — кино»).

## 4. Как это работает для Жени

- На главном экране: приветствие с аистом Буселом, шкала до награды, серия дней 🔥, цель на сегодня, кнопка «Продолжить» и плитки предметов.
- Урок идёт по шагам: **объяснение → разобранный пример → «Проверь себя» → практика → бонус (по желанию) → итог**.
- За ошибки баллы **не отнимаются**. Приложение мягко разбирает решение и даёт похожее задание. Первая подсказка бесплатная, вторая уменьшает баллы вдвое.
- Баллы: обычное задание — 10, повышенное — 20, бонусное — 30, комбо из 5 подряд — +10, тема на 80% и выше — +50 и значок, дневная цель — +20.
- После каждой пройденной темы — сундук-сюрприз (стикер, наряд для Бусела или баллы). Наряды также открываются за новые уровни.
- Серия дней: один пропущенный день в неделю прощается автоматически («заморозка» ❄️). Ничего не пропадает.

## 5. Как выдавать награды

Когда Женя набирает порог, на весь экран появляется поздравление: «Женя, ты заработал 100 баллов! 🎁 Подойди к родителям и попроси свою награду». На главном экране остаётся значок 🎁 с числом невыданных наград.

Когда выдали награду: 🔒 → PIN → **«Награды»** → кнопка **«Выдана»**. Статус сменится на «Выдана ✓».

## 6. Статистика

🔒 → **«Статистика»**: время занятий по дням (за неделю), процент правильных ответов по предметам, пройденные и начатые темы, темы с частыми ошибками.

## 7. Что есть сейчас

**Предметы и темы (все уроки готовы):**
- **Математика** — 20 тем по учебнику 5 класса; к 7 темам есть мультуроки (НОД и НОК, признаки делимости, простые числа, числовые выражения, уравнение, задачи с уравнениями, угол).
- **История Древнего мира** — 60 тем по учебнику (части 1 и 2).
- **Человек и мир** — 31 тема по учебнику 2022 года.
- **Английский язык** — 41 тема по 5 юнитам учебника и повторение; 15 наборов слов с озвучкой, карточками и повторением по системе Лейтнера.
- **Искусство** — 34 темы по учебнику.
- **Кругозор** — 50 тем (космос, природа, человек, наука, история и культура, этикет).

Русский, белорусский языки и литература убраны по вашей просьбе.

**Важно проверить:** все тексты написаны мной оригинально по темам ваших учебников. Темы «Кругозора» вы ещё не сверяли — для них я готовлю список фактов (цифры, даты, названия) по 10 тем в неделю: просмотрите и напишите, что поправить. Остальные сомнительные места собраны в `smart-busel/CONTENT_REVIEW.md`.

## 8. Озвучка английских слов

Приложение использует голоса Windows. Если слова не озвучиваются (на экране слов будет подсказка 🔇):
**Параметры Windows → Время и язык → Язык и регион → Добавить язык → English (United States)**, затем в его параметрах скачайте пакет **«Речь»** (Speech). После этого перезапустите приложение.

## 9. Резервные копии и перенос прогресса

- Прогресс сохраняется автоматически в `C:\Users\<имя>\AppData\Roaming\Умный Бусел\data.json`.
- При каждом запуске приложение делает копию в папке `backups` рядом (хранятся последние 7).
- Вручную: 🔒 → **«Копия»** → **«Сохранить в файл»** (и «Загрузить из файла» на другом компьютере).

## 10. Если что-то пошло не так

- **Забыли PIN.** Закройте приложение, откройте папку `C:\Users\<имя>\AppData\Roaming\Умный Бусел`, откройте `data.json` в Блокноте, найдите строку `"pin"` и впишите новое значение (например, `"pin": "0000"`). Сохраните.
- **Приложение не открывается.** Переустановите его: прогресс останется на месте (хранится отдельно от программы).
- **Удалить приложение:** Параметры → Приложения → «Умный Бусел» → Удалить.
- **Забыли PIN на телефоне.** Если синхронизация включена — смените PIN на компьютере, через минуту-другую он придёт на телефон. Если нет — напишите мне.

## 11. Android: установка на телефон или планшет

Нужен Android 7.0 или новее. Google Play для этого не нужен.

1. На телефоне откройте страницу выпусков репозитория на GitHub (**Releases**) и скачайте файл `Umny-Busel-X.Y.Z.apk` из самого верхнего выпуска (X.Y.Z — номер последней версии).
2. Откройте скачанный файл. Android спросит: «Разрешить установку из этого источника?» — разрешите для браузера (или «Файлов»), нажмите **«Установить»**.
3. Если появится окно Google Play Защиты «Приложение не проверено» — нажмите **«Подробнее» → «Всё равно установить»**. Это обычное предупреждение для приложений не из Google Play.
4. Значок с Буселом появится на рабочем столе. При первом запуске: 🔒 в правом верхнем углу главного экрана → PIN **0000** → сразу смените PIN (если прогресс переносится синхронизацией — PIN придёт с компьютера).

**Обновления:** начиная с версии 1.7.0 ставятся сами (раздел 14). Один раз разрешите их в родительском режиме — кнопка «Разрешить».

**HONOR (MagicOS) и другие телефоны.** На HONOR 90 Lite (MagicOS 9, Android 15) всё работает так же; отличаются только названия пунктов:
- при первой установке телефон попросит разрешить установку **браузеру** или приложению **«Файлы»** — включите переключатель «Разрешить установку приложений» и вернитесь назад;
- если MagicOS предложит «проверить приложение» или покажет предупреждение о безопасности — выберите **«Продолжить установку»** (приложение не из магазина, это обычное предупреждение);
- если что-то не находится — в Настройках есть поиск (лупа вверху): наберите «установка из внешних источников» или «синтез речи».

**Что на телефоне иначе:** меню — внизу экрана; кнопка/жест «Назад» возвращает на предыдущий экран; «Распечатать» грамоты открывает окно печати Android (там же «Сохранить как PDF»); «Сохранить в файл» (копия прогресса) открывает «Поделиться» — можно отправить файл себе или сохранить на Диск.

**Озвучка английских слов на Android:** Настройки → поиск «синтез речи» (обычно Специальные возможности или Система → Язык и ввод → Синтез речи) → выберите **«Синтез речи Google»** (если его нет — установите «Speech Services by Google» из Google Play) → в его настройках установите английский (English (United States)).

## 12. Синхронизация Windows и Android

Баллы, темы, награды, ошибки, слова и статистика становятся общими: что Женя сделал на телефоне, видно на компьютере, и наоборот. Без интернета всё работает как обычно и синхронизируется позже.

**Безопасность.** Прогресс шифруется прямо на устройстве **семейным кодом** (20 знаков, его придумывает приложение). В облаке Google хранится только шифр: ни имени, ни PIN, ни баллов там прочитать нельзя — ни Google, ни кому-либо ещё. Код знают только ваши устройства. На Windows код хранится зашифрованным средствами Windows, на Android — в закрытой папке приложения (в резервные копии не попадает).

### Шаг 1 (один раз). Создать бесплатный проект Google Firebase — около 15 минут

Нужен любой Google-аккаунт (лучше ваш, а не Жени). Платить ничего не нужно, банковскую карту не привязывайте.

1. Откройте **console.firebase.google.com** → **«Создать проект»** (Create a project). Имя — например, `umny-busel`.
2. Когда спросят про **Google Analytics — выключите** (он не нужен; для детского приложения лучше без него). Нажмите «Создать проект».
3. Слева: **Build (Сборка) → Authentication** → «Начать» (Get started) → вкладка **Sign-in method** → **Anonymous (Анонимный)** → включить → «Сохранить».
4. Слева: **Build → Firestore Database** → «Создать базу данных» (Create database) → расположение — Европа (`eur3` или `europe-west`) → **production mode (рабочий режим)** → «Создать».
5. В Firestore откройте вкладку **Rules (Правила)**, сотрите весь текст и вставьте содержимое файла **`smart-busel/firestore.rules`** из репозитория → **«Опубликовать»** (Publish).
6. Значок шестерёнки слева вверху → **«Настройки проекта»** (Project settings) → внизу «Ваши приложения» → значок **`</>`** (Web) → имя «Умный Бусел» → «Зарегистрировать» (Firebase Hosting не включайте).
7. Появится текст `firebaseConfig = { apiKey: "...", ..., projectId: "..." }`. **Пришлите мне два значения: `apiKey` и `projectId`.** Они не секретные (их видно в любом приложении с Firebase; защищают данные правила из шага 5 и шифрование). Я впишу их в `src/sync/firebase-config.json`, и новая версия соберётся сама.

*Необязательно, для дополнительной защиты:* console.cloud.google.com → ваш проект → «API и сервисы» → «Учётные данные» → ключ «Browser key (auto created by Firebase)» → «Ограничения API» → оставьте только **Identity Toolkit API**, **Token Service API** и **Cloud Firestore API** → «Сохранить».

### Шаг 2. Включить синхронизацию

1. **На компьютере:** 🔒 → PIN → вкладка **«Синхронизация»** → **«Это первое устройство — создать код»**. Появится код вида `ABCD-EFGH-JKMN-PQRS-TVWX`.
2. **На телефоне:** 🔒 Родителям → PIN → **«Синхронизация»** → **«Подключиться по коду»** → введите код (дефисы и регистр не важны) → «Подключиться».
3. Если на телефоне уже был прогресс, приложение спросит:
   - **«Сложить»** — если Женя занимался на телефоне отдельно: баллы и темы прибавятся к общим;
   - **«Заменить»** — если на телефон раньше загружали копию прогресса с компьютера (чтобы ничего не удвоилось).

Синхронизация происходит сама: при запуске, через минуту-полторы после занятий, каждые 5 минут и когда приложение сворачивают. Кнопка «Синхронизировать сейчас» — для нетерпеливых.

**Что общее, а что у каждого устройства своё.** Общее: баллы, награды, темы и звёзды, ошибки, слова, значки, грамоты, план на сегодня, PIN, имя, пороги наград, дневная цель и лимит времени (лимит считается по сумме времени на всех устройствах). У каждого устройства своё: тема оформления, размер шрифта, звук.

### Если телефон потерян

Вкладка «Синхронизация» на компьютере → **«Сменить код (устройство потеряно)»**. Старые данные в облаке удалятся, потерянный телефон больше ничего не получит. На остальных устройствах введите новый код и выберите **«Заменить»**.

### Отключить или удалить

- **«Отключить на этом устройстве»** — прогресс на устройстве остаётся; подключить снова можно тем же кодом.
- **«Удалить данные из облака»** — всё удаляется из облака Google, синхронизация выключается; прогресс на каждом устройстве остаётся.
- Загрузить копию из файла («Копия» → «Загрузить из файла») можно только при выключенной синхронизации — иначе прогресс мог бы удвоиться.

## 13. Ключ подписи Android (один раз)

Каждая версия APK подписывается одним и тем же ключом — иначе Android не даст обновить приложение поверх старого (пришлось бы удалять его вместе с прогрессом). Ключ я создал; GitHub должен его знать, а в репозитории его нет:

1. GitHub → репозиторий → **Settings → Secrets and variables → Actions → New repository secret**.
2. Создайте четыре секрета (имя — как ниже, значение — содержимое одноимённого файла, который я прислал):
   `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.
3. Файл `umny-busel-release.jks` и пароль **сохраните в надёжном месте** (например, в менеджере паролей). Если ключ потерять, новые версии придётся ставить с удалением старой.

Пока секретов нет, GitHub собирает пробную версию `...-test.apk` (её можно установить, но обновлять потом придётся с удалением).

## 14. Новые версии и автообновление

**Новые версии ставятся сами — и на компьютере, и на телефоне.** Когда я поднимаю номер версии и изменения сливаются в `main`, GitHub собирает установщик для Windows и APK для Android и выкладывает их на странице выпусков. Дальше программы обновляются без вас. Прогресс при обновлении не трогается.

**Один раз вручную.** Версию 1.7.0 нужно поставить самому (раздел 2 — Windows, раздел 11 — телефон): в старой версии 1.6.0 автообновления ещё нет. Начиная с 1.7.0 всё происходит само.

**Windows.** Программа раз в 4 часа проверяет, есть ли новая версия, скачивает её в фоне, сверяет контрольную сумму и **тихо ставит, когда программу закрывают**. При следующем запуске — уже новая версия. В родительском режиме видно «Новая версия … готова» и есть кнопка «Перезапустить и обновить», если хочется сразу.

**Android (телефон HONOR).** Приложение проверяет GitHub, скачивает новую версию в фоне и **ставит её, когда приложение свёрнуто** (через 5 секунд; если Женя сразу вернулся — установка подождёт). Перед установкой приложение проверяет файл: это тот же «Умный Бусел», версия новее, и он подписан тем же ключом (раздел 13). Чужой или подменённый файл не установится.
- **Один раз нужно разрешение.** После установки 1.7.0 зайдите в 🔒 «Родителям» — там будет жёлтая карточка «Включите автообновление» → **«Разрешить»** → включите «Разрешить установку из этого источника» → «Назад». Пока разрешения нет, на кнопке «Родителям» горит жёлтая точка.
- **Иногда телефон всё же спросит.** Android может попросить подтвердить обновление («Обновить?») — например, если оболочка телефона (MagicOS) так настроена. Тогда в родительском режиме будет кнопка «Обновить сейчас» → «Обновить». Это решение самой системы Android, обойти его приложение не может.
- Если скачать не получилось (нет интернета) — приложение попробует позже; в родительском режиме есть «Скачать вручную».

Внизу родительского режима видно текущую версию; на телефоне есть «Проверить сейчас».

## 15. Google Play (если захотите выложить)

Для своей семьи Google Play не нужен — достаточно APK (раздел 11). Если всё-таки захотите:

1. **Аккаунт разработчика Google Play** — разовый взнос **25 $**, нужен документ, удостоверяющий личность, и карта на ваше имя (Беларусь в списке стран для регистрации есть). Для личного аккаунта — **закрытое тестирование: 12 тестировщиков в течение 14 дней** подряд, только потом можно публиковать для всех. Для аккаунта организации (нужен номер D-U-N-S) этого требования нет.
2. **Файл для загрузки** — `Umny-Busel-1.7.0.aab` (AAB): его собирает GitHub Actions, он лежит в артефакте `umny-busel-android`. Требование Google: приложение нацелено на Android 16 (API 36) — у нас так и есть.
3. **Подпись:** включите «Подписание приложений в Google Play» (Play App Signing); наш ключ станет «ключом загрузки».
   **Важно:** версия для Google Play должна быть без нашего автообновления — Google Play сам обновляет приложения и не разрешает приложениям ставить APK (разрешение REQUEST_INSTALL_PACKAGES). Если решите публиковать — скажите, я сделаю отдельную сборку для Play.
4. **Политика конфиденциальности** по открытой ссылке — текст готов: `smart-busel/PRIVACY_POLICY.md` (впишите адрес почты для связи).

- **Статусы тем:** «Не начата», «Начата», «Не пройдена» (тему прошли, но нужных 80% нет), «Пройдена». Видны у каждой темы, на главном экране и в родительском режиме.
- **Мой план на сегодня:** Женя сам выбирает любые темы на день (кнопка «Выбрать темы» на главном экране или «+ В план» у темы). Темы по-прежнему идут по порядку программы, метка «По порядку» подсказывает следующую.
- **Грамоты:** за тему на 100%, пройденный раздел, предмет и серию 7/14/30 дней. Открываются в «Моя коллекция» → «Мои грамоты», кнопка «Распечатать» (в окне печати можно выбрать «Сохранить как PDF»).
- **Работа над ошибками:** кнопка на главном экране; повторяются задания, в которых были ошибки. Без штрафов.
- **Отчёт за неделю:** родительский режим → «Отчёт за неделю»: время, дни, задания, пройденные темы, где ошибки, советы. Можно распечатать или скопировать.
- Исправлена ошибка: в некоторые дни третье задание дня показывалось пустым.
