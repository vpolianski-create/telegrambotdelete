# «Умный Бусел» — План (Этап 1)

## 0. Важные замечания
- В репозитории уже лежит другой проект (Telegram Bot Cleaner, Python). Новое приложение — в отдельной папке `smart-busel/`, старый код не трогаем.
- Сессия идёт в облаке (Linux), а `.exe` нужен для Windows 11. Установщик будем собирать **на GitHub Actions (windows-latest)** — в репозитории уже есть такой workflow. Вы скачиваете готовый `.exe` из вкладки Actions/Releases. Локально на вашем ПК Node.js нужен только если захотите запускать/менять код сами.
- adu.by и resheba.top проверю на доступность в Этапе 4; если нет доступа — перечень тем по моим знаниям + `CURRICULUM_REVIEW.md` для сверки с учебниками.

## 2. Экраны
1. Главный: приветствие + Бусел, шкала до награды, серия дней, «Продолжить», ежедневная цель, значок невыданных наград, карта островов.
2. Карта предмета (остров с тропинкой тем).
3. Урок: карточки объяснения → пример → «Проверь себя» → практика → бонус.
4. Итог темы (проценты, баллы, что повторить, сундук-сюрприз).
5. Полноэкранная награда (конфетти) и повышение уровня.
6. Английский: «Мой словарь», 5 режимов тренировки, Лейтнер.
7. Достижения и коллекция (значки, аксессуары, стикеры).
8. История наград (ребёнок видит «Ожидает»/«Получена ✓»).
9. Родительский режим (PIN): статистика, награды, настройки, свои задания, экспорт/импорт.
10. Экран перерыва / «Отличная работа на сегодня!».

## 3. Схемы данных (Zod)
- **Subject**: id, title, color, icon, language, sections[] → topics[] (id, title, needsReview?).
- **Topic**: explanation cards[], workedExample{steps[{text, why}]}, selfCheck[], practice[] (задания или ссылки на генератор), bonus[].
- **Task**: id, subject, topicId, difficulty (basic|advanced|bonus), type (single | multi | input | match | order | fill | truefalse | fraction), question, options?, answer, explanation[], hints[], needsReview?. Для генераторных: `generator: "math.addFractions"`, `params`.
- **Word**: id, en, transcription, ru, example, topic.
- **Progress** (JSON в userData): points, level, streak{days, freezeUsedWeek}, topicResults{topicId: {bestPercent, attempts, done}}, mistakes[], leitner{wordId: box, nextDue}, badges[], accessories[], stickers[], rewardsHistory[{threshold, text, status, date}], dailyLog{date: {minutes, tasks, correct}}.
- **Settings**: PIN (хэш), name, rewardThreshold, rewardsList, dailyGoal, dailyLimit, breakEvery, sound, theme, fontScale.
- Бэкап `progress.backup-<дата>.json` при каждом запуске (хранятся последние 7).

## 4. Перечень предметов и тем (черновик — сверить с учебниками, см. CURRICULUM_REVIEW.md)
- **Математика**: натуральные числа и действия; делимость (признаки, НОД, НОК); обыкновенные дроби (сложение/вычитание, сравнение); десятичные дроби; уравнения и текстовые задачи; геометрия (углы, периметр, площадь); проценты (введение).
- **Русский язык**: фонетика и орфография; состав слова; части речи (существительное, прилагательное, глагол); словосочетание и предложение; синтаксис простого предложения.
- **Русская литература**: сказки, басни, стихи, рассказы — по авторам из программы (needsReview).
- **Беларуская мова**: фанетыка, лексіка, марфалогія (назоўнік, прыметнік, дзеяслоў), правапіс (ў/у, і/ы, ‑ц-/‑ць-…) — needsReview.
- **Беларуская літаратура**: фальклор, творы беларускіх пісьменнікаў — needsReview.
- **История**: в 5 классе по действующей программе — «История Беларуси/всемирная история» (уточню по adu.by; даты — needsReview).
- **Английский**: грамматика (to be, Present Simple, have got, there is/are, can, артикли, множественное число, предлоги); словарь по темам: семья, школа, еда, животные, хобби, распорядок дня, дом, одежда, погода.
- **Человек и мир**: проверю, есть ли в 5 классе (обычно в 1–4); если нет — убираем.

## 5. Игровая логика (кратко)
Баллы 10/20/30, комбо +10 за 5 подряд, тема ≥80% → +50 и значок, дневная цель +20. Награда — при пересечении порога (считаем «сколько порогов пройдено − сколько уже создано», чтобы не потерять и не задвоить). Ошибки без штрафов; подсказка 1 бесплатна, 2-я = половина баллов. Заморозка серии раз в неделю автоматически.
